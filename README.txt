
This is Minesweeper, but it can display number in different forms.

you have four ways to display the number:
1. Classic, which just shows the number normally
2. Binary, for computer science engineers, it displays numbers in binary, only 0 & 1
3. Maths, display numbers in simple maths expression, only basic arithmetic (+,-,×,/)
4. HarderMaths, display numbers in maths expression, it is harder, required knowledge up to A-level maths in the UK

there are also a few options of gameboard size:
1. Beginner, size of 9×9 with 10 mines
2. Intermediate, size of 16×16 with 40 mines
3. Expert, size of 16×30 with 99 mines
4. Custom, set any size and number of mines as you want, but I don't recommend the size over 50×50

If you don't know how to play minesweeper, here are the rules:
1. your job is to find all safe spots, where have no mine on it
2. the gray boxes are unrevealed, you can either left click to reveal them or right to flag/unflag them
3. the white boxes are revealed, you can't click them, they may show a number
4. the number on a white box means how many mines are there next to it in the surrounding 3×3 area
    for example, number 1 means there is one mine surrounding it, number 2 means there are two mines surrounding it, etc
5. If you click a mine, the game is over.

Also, sometimes you may need to guess the position of a mine, such as when facing a 50/50 scenario.

Anyways, hope you have fun with it!





Additional information:
This game is ready to run, portable, no installation required,
and no leaderboard as it doesn't save anything in your computer.
So remember to write down your personal best if you do care about it.

The "MathsExpression.json" file is necessary to play HarderMaths, if you change it and it is unusable, or lost it,
 download the "MathsExpression.json" file from Github and put it next to the executable file of this game,
 replace the older one if needed.
